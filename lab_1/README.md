# Менеджер паролей

Консольное приложение на Python для локального хранения учётных данных. Менеджер позволяет создать хранилище, защитить его мастер-паролем, добавлять и удалять записи, просматривать список сохранённых сервисов и получать логин и пароль после повторного подтверждения мастер-пароля.

Пароли записей шифруются с помощью Fernet, а мастер-пароль не сохраняется в открытом виде: в JSON-файле хранится только его проверочный хэш и соль.

## Требования

- Python версии **3.11 или новее**.
- Установленный [uv](https://docs.astral.sh/uv/).

## Установка

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone https://github.com/yarqr/python-course.git
cd python-course/lab_1
```

Создайте виртуальное окружение и установите зависимости:

```bash
uv sync
```

## Запуск

Приложение можно запускать как установленную CLI-команду:

```bash
uv run pwmanager --help
```

Также доступен запуск в виде Python-модуля:

```bash
uv run python -m pwmanager --help
```

### 1. Создание хранилища

При первом запуске выполните:

```bash
uv run pwmanager --init
```

Программа запросит мастер-пароль и его подтверждение. Ввод скрыт. После успешной проверки совпадения будет создан файл хранилища.

### 2. Вход в хранилище

```bash
uv run pwmanager --unlock
```

Введите мастер-пароль. При успешной проверке откроется интерактивное меню:

```text
=== МЕНЕДЖЕР ПАРОЛЕЙ ===
add - добавить запись
list - показать названия записей
get - найти и показать запись
delete - удалить запись
exit - выйти из менеджера паролей
```

### 3. Команды меню

| Команда | Назначение |
|---|---|
| `add` | Добавить запись. Программа запросит название, логин и пароль. |
| `list` | Показать названия всех сохранённых записей без логинов и паролей. |
| `get` | Получить запись по названию. Для просмотра программа повторно запросит мастер-пароль. |
| `delete` | Удалить запись по названию. |
| `exit` | Завершить работу с открытым хранилищем. |

При добавлении пароль записи вводится скрыто. Пустые названия, логины и пароли не принимаются. Названия записей должны быть уникальными.

### 4. Генерация пароля

Сгенерировать пароль стандартной длины:

```bash
uv run pwmanager --generate
```

Указать собственную длину:

```bash
uv run pwmanager --generate --length 24
```
